Privacy Policy

Last Updated: October 21, 2026

1. Local developer tooling

Kineti stores project state, test receipts, spending records and local history on the machine where you run it. Kineti does not provide a hosted runner, evaluator service or shared account platform.

2. Configured hosts and services

Your chosen coding host, model provider and infrastructure have their own data handling rules. Outbound request records are local records, not a network filter. Review the data you send through each configured service.

3. Memory deletion and backups

The local contextual-memory API removes the selected encrypted content and its local key and records a deletion marker. Copies in backups, filesystem snapshots or external services are outside this operation. Immutable audit records may retain permitted metadata.

4. Spending and credentials

Spending limits use recorded usage and do not represent a provider invoice or control every host action. Keep credentials in protected environment or file inputs, not command arguments or journal text.
