# PART A — Launch plan

## 1. What we are launching

Free open-core CLI that keeps AI coding agents safe: spend cap that stops
work at the limit, undo stack for every change, test proof bound to the
exact code bytes. Paid hosted dashboard for people and teams who want the
same safety visible in a browser. Rust binaries, `cargo install`,
`kineti run`, receipts, and all v0.2.x material are retired and stay buried.

# PART B — World-class execution spec

Bar: OpenAI/Anthropic security lets it through; a top founder could demo
it without a caveat slide. Standing rules while executing: plain words,
numbered choices; spend check before heavy work; undo step before every
change; evidence run per change, never claim green without running;
secrets scan before every commit; nothing outside the project folders.

## Phase 0 — Trust blockers

**0.1 MCP shell removal** (`bin/kineti-mcp.ts:253,298`,
`bin/kineti-evidence.ts:61-64`, `bin/kineti-saga.ts:100`). Replace
`bash -lc` with argv-array spawn; `kineti_evidence_record` and
`kineti_saga_push` take command arrays against an allowlist (`bun test`,
`pytest`, `npm test`, project verify); anything else needs an explicit
human `--allow-shell` flag plus TTY confirm; 60s timeout; `cwd` jailed to
workspace root; every invocation appended to the egress ledger. Tests:
`; rm` and `$()` payloads execute nothing and exit non-zero; timeout test
with `sleep 70`. Acceptance: `grep -rn "bash.*-lc" bin/` returns only the
flagged human path.

**0.2 Companion auth completion** (`bin/kineti-companion.ts:515`, `/`,
`/api/status`, `/api/fleet`, settings GET). Delete token embedding; serve
the page token-free; require `isAuthorized` on every `/api/*` route
including reads; validate `Host` against `127.0.0.1:$PORT` /
`localhost:$PORT` to kill DNS rebinding; add `Vary: Origin`,
deny-by-default CORS. Tests: unauthenticated `GET /` is 401 with no hex
token in body; rebinding Host rejected; existing origin tests still pass.

**0.3 Stored-execution hardening.** Saga rollback prints each inverse with
its hash and requires interactive `y/N`; refuses when `saga.jsonl`
owner/mtime changed since push. Verify-gate: delete
`KINETI_TRUST_CONFIRMED` bypass, require TTY plus typed hash echo, fail
closed on empty `verify_command`. Tests: planted `rm -rf ~` inverse never
runs silently; env bypass ignored.

**0.4 Spend finite discipline** (`bin/kineti-spend.ts:86-116`,
`bin/lib.ts:80-88`, `bin/kineti-ci.ts:134`). `Number.isFinite` on all
token/usd/limit inputs (exit 2 otherwise); `loadLimits` clamps to
defaults; CI calls `loadLimits(workspaceRoot)` instead of hardcoded 50M.
Tests: NaN/negative/`"lots"` inputs rejected; $1 custom cap enforced
in CI.

**0.5 CI gate closure** (`bin/kineti-ci.ts:108-176,199-217`). Stage-0
requires `security != fail` plus fresh evidence; all records in the window
must be exit-0 (one appended pass cannot mask failures); markdown-escape
`rootGoal`/`failures`. Tests: `stage bypass + security fail` → BLOCKED;
poisoned evidence history → BLOCKED; markdown injection posts inert text.

**0.6 Journal integrity upgrade** (`bin/kineti-memory-job.ts:63-114`).
Hash `[prev_hash, at, id, type, state, project, canon(data), canon(links),
expires]` with `computeDelimitedHash` only; one migration re-signs the
existing records and notes the format bump; legacy acceptance deleted.
Tests: flipping `state` or `links` breaks `verify-chain`; old-format
record rejected with a migration hint.

**0.7 Swarm honesty** (`src/swarm/coordinator.ts:116-139,215-229`,
`bin/kineti-swarm.ts:15-53`). Either add `verifyTaskDelegation`
(coordinator signature + ±5min timestamp + budget ceiling) called at the
top of worker submit and review-sign, with tampered-goal negative tests —
or label README, site, and CLI output "local simulation". No middle ground.

**0.8 State input discipline** (`bin/kineti-state.ts:34-52,110-168`).
Whitelist `task.* ∈ {type,name,step}`, `gate.* ∈
{spec,feasibility,security,ship}`; `Object.hasOwn` guards;
`Object.create(null)` stores; strict `gates`/`history` validation. Tests:
`task.__proto__` write refused; `stage ship-bypass` refused.

**0.9 Installer verification** (`install.sh`, adopting the site's
`public/install.sh` as source). Fetch `SHA256SUMS`, verify before
chmod/install, trap cleanup of temp, pin repo allowlist, never sudo
without refusal path, keep `linux-arm64` absence explicit. Tests: tampered
byte → fail closed; cover with a local-file-server install test.

**0.10 Gate for the phase.** Full suite + smoke green, evidence fresh,
local CI PASSED, security re-pass with zero critical/high findings,
secrets scan clean. Commit `security-fix` series, push.
