# Kineti hook block for Google Antigravity
Add the following to your project or user rules:
  Follow the Kineti workflow skills installed in the skills directory. Users
  can describe the task in natural language; do not require slash commands.
  For a new project, ask the user to choose harness, gate, or both before
  setup. Direct fixes, reviews, and cleanup can start at the relevant step.
  Check the active goal and relevant approvals before changing project files.
  These instructions provide guidance; only separately tested capabilities
  are enforcement.
