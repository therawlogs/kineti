kineti0.6.0 · published

Check before you ship.

Run your tests. Record what they checked. If the inputs change, Kineti tells your CI to stop until fresh checks pass.

Add Kineti before your release command. It checks test evidence and reported spending limits. It only gates workflows that explicitly use it.

Install with npm
npm install -g kineti@0.6.0
Or with Cargo
cargo install kineti-cli --version '=0.6.0' --locked

Linux + macOS · x64 + arm64
