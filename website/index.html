Linux and macOS · x64 and arm64. GitHub Actions CI and MCP for your coding agent. Verified with Codex; other agents are unverified. Compatibility details ↗

Kineti only gates workflows that explicitly use it. No automatic interception or protected writes. Signed records don’t prove honest tests. Reported costs aren’t provider bills.
