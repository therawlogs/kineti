Requirements and important limits

Kineti is proprietary. The source repository is private. npm installation requires Node.js 18 or later and enabled installation scripts; the installed native executable does not require Node.js.

Kineti supports participating CI and MCP for your coding agent. MCP integration tested on macOS arm64 with Codex 0.163.0-alpha.11.2 and 0.164.0. Other versions and agents are unverified.

Kineti only gates workflows that explicitly use it. No automatic interception or protected writes. Signed records don’t prove honest tests. Reported costs aren’t provider bills.

Record checks, detect changed inputs, and block participating CI commands when evidence or reported spending fails policy.
