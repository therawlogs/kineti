# v0.1 — 13-stage runner (frozen)

> This document freezes the `v0.1.0` pipeline that shipped 2026-08-25. The active product is `v0.2` — see `README.md` (gateway + receipt). This file is the reference if you stay on the old tag or run `kineti run --legacy`.

Tag: `v0.1.0` (`git checkout v0.1.0`), commit `9335fef`. Apache-2.0, forkable.

## The 13 stages (WORKFLOWS.md)

```
1 officehours ─► 2 diagnose ─► 3 design ─► 4 architecture
        ▲                                          │
        │                                          ▼
        │                              5 FEASIBILITY GATE ◄─┐
        │                              (fail → back to 2)   │ fail
        │                                          │ pass   │
        │                                          ▼        │
        │                                   6 SPEC [STOP]   │
        │                                   human approval  │
        │                                          │ approved
        │                                          ▼
        └── 13 retro + learn ◄─ 12 watch ◄─ 11 ship ◄─ 10 security ◀─ 9 qa ◀─ 8 review ◀─ 7 build
```

Hard rules at the time: feasibility fail loops to diagnose; spec requires human `y`; ship refuses without fresh proofs + passed security + clean journal + clean-files scan.

## Commands (v0.1 shape)

```
kineti init
kineti run --goal "…" [--mode single|swarm] [--cap 100]
kineti resume
kineti task --task "…"
kineti evidence --cmd "cargo test"
kineti ship-check
kineti verify --all
kineti receipt
# plus worktree/swarm isolation, DAG branch merges, etc.
```

## What 0.2 demoted

All of the above still compiles under `--features legacy` / hidden `run`/`resume`/`undo`/`merge` but is no longer the homepage. The meter+stamp path is `evidence → ship-check → verify`.

## Running the old pipeline

```sh
git checkout v0.1.0
cargo run -- run --goal "Create greeting.sh that prints KINETI SHIPS"
# or on v0.2 binary (compatibility shim):
kineti run --goal "…"   # prints legacy warning then drives stages::drive
```

No further changes will be made on `v0.1` branch.
